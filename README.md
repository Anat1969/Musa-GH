# מוזה (Muse Meridian)

סטודיו לתרגום השראה למרחב אדריכלי. כותבים ספר, שיר, יוצר או מחשבה, בוחרים אופן תרגום (לוח השראה, המחשה, מרחב מחודש), ומקבלים קריאה מרחבית, צילום אדריכלי ופרשנות קצרה בעברית. כל מחקר נשמר בארכיון לפי המקור.

- Vite + React + framer-motion, Supabase (cultura-GH), Claude ו-fal.
- `npm install`, `npm run dev`. בדיקות: ראו `CLAUDE.md`.
